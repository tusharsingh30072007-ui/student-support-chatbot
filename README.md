# 🎓 Student Support AI Chatbot

An AI-powered chatbot designed to help students with common academic and campus-related queries.

## 🚀 Features

- 🤖 AI-based student support chatbot
- 🧠 Intent classification using Machine Learning
- 🔤 TF-IDF text vectorization
- 📊 Logistic Regression classification
- 💬 Interactive Streamlit interface
- 📚 Supports 20 different student-service intents
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Streamlit
- TF-IDF
- Logistic Regression

## 📌 Supported Services

The chatbot can handle queries related to:

- Attendance
- Examinations
- Assignments
- Fees
- Courses
- Timetable
- Library
- Scholarships
- Results
- College Facilities
- Hostel
- Placements
- Internships
- ID Card
- Transport
- Clubs & Events
- Admission
- Contact & Support
- Greetings
- Goodbye

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/tusharsingh30072007-ui/student-support-chatbot.git
cd student-support-chatbot
pip install -r requirements.txt
streamlit run app.py
```
